# Ball tree 插图与正文片段

## 一、左图（二维几何示意）正文 — LaTeX 环境

图以二维平面示意 Ball tree 上 **k 近邻查询** 的空间关系。图中**蓝色实线大圆**表示根结点对应的闭球 \(B_{\mathrm{root}}\)，其球心为 \(c_{\mathrm{root}}\)、半径为 \(r_{\mathrm{root}}\)，覆盖全树训练样本（图中绿、橙散点）；**绿色与橙色虚线圆**分别表示左、右子树结点对应的闭球 \(B_L\)、\(B_R\)，用于表达层次划分。散点中绿色、橙色分别表示当前划分下落入左、右子树的样本点。红色星形为**查询点** \(q\)，其可位于根球之外，以体现「查询不必落在训练点集凸包或根球内部」的常见情形。图中由 \(q\) 到 \(c_{\mathrm{root}}\)、\(c_R\) 的虚线段仅作几何提示，便于理解查询点到各球球心的欧氏距离 \(d(q,c)\) 在剪枝下界中的作用。左下角文字给出结点球的**距离下界**与剪枝判据，与下文公式一致。

**文末公式（与符号一致）：**

\[
d(q,c)=\lVert q-c\rVert_2=\sqrt{\sum_{i=1}^{d}(q_i-c_i)^2},\qquad
\mathrm{LB}(B)=\max\bigl(0,\; d(q,c)-r\bigr).
\]

训练点 \(p\) 属于闭球 \(B=(c,r)\) 当且仅当 \(\lVert p-c\rVert_2\le r\)。根球包含全树训练点集 \(\mathcal{P}\) 时，有 \(\forall p\in\mathcal{P},\;\lVert p-c_{\mathrm{root}}\rVert_2\le r_{\mathrm{root}}\)。剪枝时，若已维护当前第 \(k\) 近邻距离上界 \(d_k\)，且 \(\mathrm{LB}(B)>d_k\)，则球 \(B\) 对应子树可整支剪去。

**文末公式（Word 中可改为公式编辑器录入）：**

（1）欧氏距离：d(q,c) = ||q-c||_2 = sqrt((q_1-c_1)^2 + ... + (q_d-c_d)^2)（下标在 Word 中可改为公式下标）。

（2）下界：LB(B) = max(0, d(q,c) - r)。

（3）点 p 在闭球 B(c,r) 内：||p-c||_2 <= r。

（4）根球包含训练集 P：对任意 p in P，有 ||p-c_root||_2 <= r_root。

（5）剪枝：若 LB(B) > d_k，则结点 B 对应子树可剪枝。

## 三、k 近邻查询算法叙述（与右栏原稿等价，非专指左图）

基于球树（Ball tree）索引的 k 近邻查询可表述如下。首先将根结点加入优先队列，并以当前第 k 近邻距离的上界 \(d_k\)（或等价地维护至多 k 个候选近邻）作为剪枝阈值；队列中结点按其下界 LB 排序，典型实现采用最小堆等结构以保证每次先扩展最有希望的子树。对任一结点所对应的闭球 \(B\)，其球心为 \(c\)、半径为 \(r\)，查询点 \(q\) 到球内任意点的距离下界可取 \(\mathrm{LB}(B)=\max(0,\, d(q,c)-r)\)。每次弹出 LB 最小的结点后，若为叶结点，则对叶内样本计算真实欧氏距离并更新 k 近邻及 \(d_k\)；若为内部结点，则将其左右子球结点分别入队，并对子结点按同样规则计算 LB。若某结点满足 \(\mathrm{LB}(B)>d_k\)，则该结点及其整棵子树均不可能提供优于当前第 k 近邻的点，可直接剪枝。当队列为空，或剩余结点的 LB 均大于 \(d_k\) 时，算法终止并输出 k 个最近邻。上述过程在工程实现中常通过优先队列按 LB 维护待扩展结点，从而在稀疏高维场景下减少无效距离计算。
